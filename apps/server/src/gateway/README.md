# storage gateway
Run mode `storage-gateway` (D.4, D.5): the `/v1` protocol on its own Fastify application (`gateway-app.ts`, HTTPS with required client certificates in `tls.mode: mtls`), bearer tokens with a current and a previous file (`auth.ts`), the per-call `gateway.call` log line, problems and metrics (`routes.ts`, `gateway-server.module.ts`). `crypto/` holds tenant data keys under `storage.key`, credential sealing bound to organisation, repository and config (D-08) and the 64 KiB chunk encryption of vault objects (D-10). `file-type.ts` detects the content type from the first 4 KiB; `streams.ts` hashes, counts and limits uploads while they pass. `adapters/` has the `StorageAdapter` interface, the registry and `managed-vault`; `m365` and `google-drive` are WP-15's and join `ADAPTER_FACTORIES` in `adapters/index.ts`. No database access.
Owner: WP-13 (adapters/m365 and adapters/google-drive WP-15).
