### Bundle contract for WP-33 (`build-bundle.sh`)

`install.sh` and `upgrade.sh` expect this layout; the current `build-bundle.sh` still makes the web-only bundle, which the new scripts refuse with "This bundle has no MSCD server image".

```text
mscd-onprem-<version>/
  VERSION, BUNDLE-INFO, SHA256SUMS (+ SHA256SUMS.sig), INSTALL-ONPREM.md
  install.sh, upgrade.sh, uninstall.sh, lib/common.sh
  compose/docker-compose.yml, compose/.env.example, compose/config/postgres/10-mscd-bootstrap.sh
  images/<files named in BUNDLE-INFO>
```

`BUNDLE-INFO` keeps `VERSION`, `IMAGE`, `IMAGE_FILE`, `IMAGE_ARCH`, `IMAGE_LAYERS` (web) and adds `SERVER_IMAGE`, `SERVER_IMAGE_FILE`, `SERVER_IMAGE_LAYERS`, and `EXTRA_IMAGE_1`, `EXTRA_IMAGE_2`, ... with the value `<image:tag> <file> <layers>` for `postgres:16.15-alpine`, `chrislusf/seaweedfs:4.48` and `valkey/valkey:8.1-alpine`. Layers are `image_fingerprint` of `lib/common.sh`. `compose/config/demo-secrets` must not be copied (`install_config` skips it anyway).
