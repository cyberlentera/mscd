Conventions for the work packages that edit area files:

- Every exported schema is created with `named(id, schema, description, {valid, invalid})`; the id equals the export name and becomes the OpenAPI component name. `test/schemas.test.ts` finds every exported zod schema and fails when the id differs, when examples are missing, when a valid example is rejected or when an invalid one is accepted.
- A route is a `defineRoute({...})` constant added to the area's `routes` array. `test/routes.test.ts` reads the D.3 and D.5 tables from the plan, so a route the plan does not list, or a plan endpoint without a route, fails the suite.
- Paths use Fastify parameters (`/api/v1/ms/:ms/...`) with the parameter names of D.3; the `params` schema must have exactly the path parameters as keys.
